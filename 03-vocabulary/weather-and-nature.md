# ⛅ Погода и природа (Sää ja luonto)

Финны очень любят обсуждать погоду — это главная тема для светской беседы (small talk) в Финляндии!

---

## 1. Погода (Sää)

| Финский | Русский | Пример использования |
|---|---|---|
| **aurinko** | солнце | *Aurinko paistaa.* (Солнце светит.) |
| **sade** | дождь | *Sataa vettä.* (Идёт дождь.) |
| **lumi** | снег | *Sataa lunta.* (Идёт снег.) |
| **tuuli** | ветер | *Tuulee kovasti.* (Дует сильный ветер.) |
| **pilvi** | облако / туча | *On pilvistä.* (Облачно.) |
| **pakkanen** | мороз | *Ulkona on pakkasta.* (На улице мороз.) |
| **helle** | жара (выше +25°C) | *Kesällä on hellettä.* (Летом стоит жара.) |
| **sumu** | туман | *On sumuista.* (Туманно.) |
| **lämmin** | тёплый | *Tänään on lämmin päivä.* (Сегодня тёплый день.) |
| **kylmä** | холодный | *On tosi kylmä!* (Очень холодно!) |

---

## 2. Разговор о температуре
- **Mikä sää tänään on?** / **Millainen sää tänään on?** — Какая сегодня погода?
- **Paljonko on lämmintä / pakkasta?** — Сколько градусов тепла / мороза?
- *On viisitoista astetta lämmintä (+15°C).* — Пятнадцать градусов тепла.
- *On kymmenen astetta pakkasta (-10°C).* — Десять градусов мороза.
