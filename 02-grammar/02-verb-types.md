# ⚡ 6 типов глаголов в финском языке (Verbin tyypit)

Все глаголы в финском языке делятся на **6 типов** в зависимости от окончания инфинитива. Зная тип глагола, вы всегда сможете правильно найти его основу и проспрягать.

---

## Личные окончания глаголов (Persoonapäätteet)

Личные окончания одинаковы для всех типов глаголов в настоящем времени:

| Местоимение | Окончание | Пример (*puhua* - говорить) |
|---|---|---|
| **Minä** (я) | **-n** | puhu**n** |
| **Sinä** (ты) | **-t** | puhu**t** |
| **Hän** (он/она) | **двойная гласная** | puhu**u** |
| **Me** (мы) | **-mme** | puhu**mme** |
| **Te** (вы) | **-tte** | puhu**tte** |
| **He** (они) | **-vat / -vät** | puhu**vat** |

---

## 6 типов глаголов

### Тип 1: Окончание на 2 гласные (`-Aa / -Ea / -Ia / -Oa / -Ua / -Yä / -Iä / -Öä`)
- **Правило:** Убираем последнюю `-a / -ä`, получаем основу.
- **Astevaihtelu:** Прямое чередование (сильная в инфинитиве, слабая в minä/sinä/me/te, сильная в hän/he).
- **Примеры:**
  - *puhua* -> *puhu-* -> *minä puhun*, *hän puhuu*
  - *kirjoittaa* -> *kirjoita-* -> *minä kirjoitan*, *hän kirjoittaa*
  - *ostaa* -> *osta-* -> *minä ostan*, *hän ostaa*

---

### Тип 2: Окончание на `-da / -dä`
- **Правило:** Убираем `-da / -dä`, получаем основу. В форме *hän* **нет** удвоения гласной!
- **Astevaihtelu:** Нет чередования согласных.
- **Примеры:**
  - *juoda* (пить) -> *juo-* -> *minä juon*, *hän juo* (без удвоения!)
  - *syödä* (есть) -> *syö-* -> *minä syön*, *hän syö*
  - *tehdä* (делать) и *nähdä* (видеть) — особые: *minä teen*, *hän tekee*; *minä näen*, *hän näkee*.

---

### Тип 3: Окончание на 2 согласные + `-a / -ä` (`-lla/-llä`, `-nna/-nnä`, `-rra/-rrä`, `-sta/-stä`)
- **Правило:** Убираем суффикс, добавляем соединительную гласную **-e-**.
- **Astevaihtelu:** **Обратное чередование** (инфинитив в слабой степени, спряжение — в сильной!).
- **Примеры:**
  - *tulla* (приходить) -> *tul- + e-* -> *minä tulen*, *hän tulee*
  - *mennä* (идти) -> *men- + e-* -> *minä menen*, *hän menee*
  - *ajatella* (думать) -> *ajattele-* -> *minä ajattelen*, *hän ajattelee* (tt сильная!)

---

### Тип 4: Окончание на гласную + `-ta / -tä` (`-ata / -otа / -utа / -etä`)
- **Правило:** Убираем `-t-`, гласная удваивается (**-Aa- / -Uu- / -Oa-**).
- **Astevaihtelu:** Обратное чередование (инфинитив слабая, формы — сильная).
- **Примеры:**
  - *haluta* (хотеть) -> *halua-* -> *minä haluan*, *hän haluaa*
  - *pelata* (играть) -> *pelaa-* -> *minä pelaan*, *hän pelaa*
  - *tavata* (встречать) -> *tapaa-* -> *minä tapaan*, *hän tapaa* (p сильная!)

---

### Тип 5: Окончание на `-ita / -itä`
- **Правило:** Убираем `-ta / -tä`, добавляем суффикс **-tse-**.
- **Astevaihtelu:** Нет чередования.
- **Примеры:**
  - *tarvita* (нуждаться) -> *tarvitse-* -> *minä tarvitsen*, *hän tarvitsee*
  - *valita* (выбирать) -> *valitse-* -> *minä valitsen*, *hän valitsee*
  - *häiritä* (мешать) -> *häiritse-* -> *minä häiritsen*, *hän häiritsee*

---

### Тип 6: Окончание на `-eta / -etä` (обозначает изменение состояния)
- **Правило:** Убираем `-ta / -tä`, добавляем **-ne-**.
- **Astevaihtelu:** Обратное чередование.
- **Примеры:**
  - *lämmetä* (нагреваться) -> *lämpene-* -> *minä lämpenen*, *hän lämpenee*
  - *vanheta* (стареть) -> *vanhene-* -> *minä vanhenen*, *hän vanhenee*

---

## Отрицание глаголов (Kieltolause)

В финском языке отрицание выражается **отрицательным глаголом**, который спрягается по лицам:

| Лицо | Отрицательный глагол | Смысловой глагол (чистая основа) | Пример |
|---|---|---|---|
| Minä | **en** | puhu | *Minä en puhu* (Я не говорю) |
| Sinä | **et** | puhu | *Sinä et puhu* (Ты не говоришь) |
| Hän | **ei** | puhu | *Hän ei puhu* (Он/она не говорит) |
| Me | **emme** | puhu | *Me emme puhu* (Мы не говорим) |
| Te | **ette** | puhu | *Te ette puhu* (Вы не говорите) |
| He | **eivät** | puhu | *He eivät puhu* (Они не говорят) |
