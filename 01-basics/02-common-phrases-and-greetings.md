# 🗣️ Базовые фразы, приветствия и знакомство

## 1. Приветствия (Tervehdykset)

| Финский | Произношение | Русский перевод | Контекст |
|---|---|---|---|
| **Hei!** | Хэй | Привет! | Универсальное, вежливое |
| **Moi!** | Мой | Привет! | Очень популярное, неформальное |
| **Terve!** | Тэрвэ | Здравствуй! / Привет! | Традиционное, нейтральное |
| **Hyvää huomenta!** | Хюваа хуомента | Доброе утро! | До 10-11 утра |
| **Huomenta!** | Хуомента | С добрым утром! | Сокращенно |
| **Hyvää päivää!** | Хюваа пяйваа | Добрый день! / Здравствуйте! | Официальное, вежливое |
| **Päivää!** | Пяйваа | Добрый день! | Нейтральное |
| **Hyvää iltaa!** | Хюваа илтаа | Добрый вечер! | После 17:00 |
| **Iltaa!** | Илтаа | Вечер добрый! | Сокращенно |
| **Hyvää yötä!** | Хюваа юота | Спокойной ночи! | Перед сном |
| **Kauniita unia!** | Кауниита униа | Приятных снов! | Близким перед сном |

## 2. Прощания (Näkemiin sanominen)

| Финский | Русский перевод | Примечание |
|---|---|---|
| **Näkemiin!** | До свидания! | Вежливое, стандартное |
| **Hei hei!** | Пока-пока! | Повсеместно используется |
| **Moi moi!** | Пока-пока! | Очень распространено в магазинах и с друзьями |
| **Heippa!** | Пока! | Дружеское |
| **Nähdään!** | Увидимся! | Буквально: "Увидимся" |
| **Nähdään huomenna!** | Увидимся завтра! | *huomenna* = завтра |
| **Palaillaan!** | Созвонимся / Еще свяжемся! | Разговорное |

## 3. Вежливость и этикет (Kohteliaisuus)

> В финском языке нет отдельного слова для "пожалуйста" (как английское *please* или немецкое *bitte*). Вежливость выражается интонацией, сослагательным наклонением (*-isi-*) и словом *kiitos*.

| Финский | Русский |
|---|---|
| **Kiitos!** | Спасибо! / Пожалуйста (при заказе: *Kahvi, kiitos* - Кофе, пожалуйста) |
| **Paljon kiitoksia!** / **Kiitos paljon!** | Большое спасибо! |
| **Ole hyvä!** | Пожалуйста! / Не за что! (в ответ на *Kiitos*) |
| **Olkaa hyvä!** | Пожалуйста! (вежливое обращение на "Вы" или к группе) |
| **Eipä kestä!** | Не стоит благодарности! |
| **Anteeksi!** | Извините! / Простите! |
| **Ei se mitään!** | Ничего страшного! / Все в порядке! |

## 4. Знакомство и первые вопросы (Tutustuminen)

| Финский | Русский перевод |
|---|---|
| **Mikä sinun nimi on?** | Как тебя зовут? |
| **Minun nimeni on...** | Моё имя... |
| **Kuka sinä olet?** | Кто ты? |
| **Minä olen...** | Я... |
| **Hauska tutustua!** | Приятно познакомиться! |
| **Mitä kuuluu?** | Как дела? |
| **Kiitos, hyvää! Entä sinulle?** | Спасибо, хорошо! А у тебя? |
| **Ei ihmeempiä.** | Ничего особенного / Потихоньку. |
| **Mistä sinä olet kotoisin?** | Откуда ты родом? |
| **Minä olen kotoisin Venäjältä / Ukrainasta / Virosta.** | Я родом из России / Украины / Эстонии. |
| **Missä sinä asut?** | Где ты живёшь? |
| **Minä asun Helsingissä / Espoossa / Tampereella.** | Я живу в Хельсинки / Эспоо / Тампере. |
| **Puhutko suomea?** | Ты говоришь по-фински? |
| **Puhun vähän suomea.** | Я немного говорю по-фински. |
| **Puhun englantia.** | Я говорю по-английски. |
| **En ymmärrä.** | Я не понимаю. |
| **Voitko toistaa?** | Можешь повторить? |
